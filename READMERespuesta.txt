¿Qué es React y como se integra con Vite y TypeScript y TSX?
React es una biblioteca de JS que se enfoca en crear interfaces de usuario basadas en componentes reutilizables
cuando algo cambia, en lugar de actualizar todo el HTML, se actualiza solo la parte específica en donde se debe observar el cambio
La combinación de estos cuatro (Vite, React, TSX y TypeScript) es el estándar de la industria del desarrollo web
- React permite dividir la pantalla en componentes
- TSX: permite escribir código HTML dentro de funciones de TypeScript
- TypeScript: Organiza el código escrito en react y le agrega tipado estático para evitar errores
- Vite: empaqueta todo y traduce typescript a código entendible para la web
